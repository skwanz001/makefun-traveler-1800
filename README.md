Entry for the [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty on make.fun.

`main.py` (Python 3.13, standard library only) writes one sentence of 135 characters to `/output/entry.txt`, explaining the modern internet to someone arriving from the year 1800 using a single picture they could hold in their head — a library holding the books and letters of the whole world, whose sought page opens the moment it is asked for. Every word in the sentence was already in use before 1800.

Run it with:

```sh
python3 main.py
```
